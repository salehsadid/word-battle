# WordBattle Dictionary

`cleaned_words.txt` is the game's word list: **17,696 common English words**, uppercase, one per line, with plurals removed. The game reads only this file and runs fully offline.

The file is generated by [`scripts/build_dictionary.py`](../scripts/build_dictionary.py). To change which words are accepted, edit the lists in that script and rebuild. Hand edits to the text file are lost on the next rebuild.

## How words are chosen

A word is kept when all of these hold:

1. **It is a real word.** It appears in ENABLE, a public-domain word-game list with no proper nouns or abbreviations.
2. **It is commonly used.** Its [wordfreq](https://github.com/rspeer/wordfreq) Zipf frequency is at least 3.0, meaning it appears about once per million words of modern English. Three-letter words need 3.3, because abbreviations and other languages inflate short-word counts. Two-letter words come from a hand-picked list (AM, AT, BE, GO, IF, ...).
3. **It is not blocked.** The script's block list removes archaic words (THEE, THOU), abbreviations and foreign short words (DUI, SRI), and offensive words. Words that NLTK's word list only has capitalised are dropped as names (JOHN, PARIS, FRENCH), except ordinary words such as BIBLE, HUNTER and MERCURY.
4. **It is not a plural.** [`wordgrid/dictionary/cleaner.py`](../wordgrid/dictionary/cleaner.py) removes regular plurals (CATS, BOXES, BABIES) and irregular ones (MICE, CHILDREN). Singular words ending in S, such as BOSS, BUS, NEWS, CLOTHES and HERS, are protected. Verb forms that look like plurals (RUNS) are removed too.

Two groups are added on top: British spellings of kept words when they are common (COLOUR, CENTRE, ORGANISE, DEFENCE; many already come from ENABLE), and modern words newer than ENABLE (EMAIL, WEBSITE, ONLINE, SELFIE).

Last build: 172,823 ENABLE words → 22,314 common → 4,618 plurals removed → 17,696 words.

## Rebuilding

```
pip install wordfreq                    # needed only to rebuild, not to play
python -m nltk.downloader words         # NLTK word list, used to spot names
curl -LO https://raw.githubusercontent.com/dolph/dictionary/master/enable1.txt
python scripts/build_dictionary.py enable1.txt
```

`python main.py --clean-dict` prints these steps.
